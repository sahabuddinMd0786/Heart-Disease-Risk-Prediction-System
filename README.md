# ❤️ MdTech AI - Heart Disease Prediction System

#  Project Overview

MdTech AI is a Machine Learning-powered web application that predicts the risk of heart disease based on a patient's medical information. The application uses a trained K-Nearest Neighbors (KNN) model and provides real-time risk assessment along with personalized health recommendations.

The project is built using Python, Streamlit, Scikit-learn, Pandas, and Joblib, providing an interactive and user-friendly healthcare dashboard.

---

# Features

* Heart Disease Risk Prediction
* Risk Percentage Calculation
* Interactive Streamlit Dashboard
* Real-Time Patient Analysis
* Personalized Health Recommendations
* Doctor Consultation Suggestions
* Responsive and Mobile-Friendly Interface
* Machine Learning Model Integration

---

##  Technologies Used

* Python
* Streamlit
* Scikit-learn
* Pandas
* NumPy
* Joblib

---

#Input Parameters

The model predicts heart disease risk using:

* Age
* Sex
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol Level
* Fasting Blood Sugar
* Resting ECG
* Maximum Heart Rate
* Exercise-Induced Angina
* Oldpeak
* ST Slope

---

# Machine Learning Model

Algorithm Used:

* K-Nearest Neighbors (KNN)

Data Preprocessing:

* Feature Encoding
* Feature Scaling using StandardScaler
* Model Serialization using Joblib

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/sahabuddinMd0786/heart-stroke-prediction-app.git
cd heart-stroke-prediction-app
```

### Create Virtual Environment (Optional)

```bash
python -m venv venv
```

### Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will start locally at:

```bash
http://localhost:8501
```
